# CurrencyStrengthElliot

## 履歴順位の前次移動（v1.38）

`CurrencyStrengthAllRankHistory` v1.14以降と組み合わせると、履歴モードの通貨順位比較に「◀ 前」「次 ▶」を表示します。日時の下へ1行追加し、現在モードでは非表示にします。最初にクリックした履歴インジケーターの保持キャッシュから、厳密に前／後の保存済みM5順位へ移動し、通貨順位・地域順位・日時・縦線を同時に更新します。表示範囲外でも保持キャッシュ内なら移動できます。追加のDB検索は行いません。

欠損や不完全な記録は飛ばします。移動間隔が5分を超える場合は「◀ 前 15分」のように表示し、ボタンのツールチップには移動先のJST日時を表示します。移動先がない側は灰色にします。「記録なし」の時刻からも、キャッシュにある前後の記録へ移動できます。前後の可否は選択・移動時点のキャッシュを反映するため、末尾へ記録が追加された後は履歴チャートを再クリックして更新できます。

長中期用・中短期用など複数の履歴窓があっても、クリック元のインスタンスIDで移動要求を限定します。別の履歴窓をクリックすると移動元を切り替えます。応答待ちは前次を灰色にし、連打で要求を増やしません。10秒以上応答がない場合は次の操作または既存Timerで待機を解除し、再試行できます。「現在へ」は応答待ちでも使用でき、戻った後の古い応答は表示へ反映しません。クリック元が削除・再初期化された場合は、保存表示を維持して前次を無効にします。

順位・クリック元ID・前後のM5間隔を固定長59文字のイベントへまとめ、移動応答は要求IDも確認します。旧形式のクリック連携は受信できますが前次は無効です。集計・候補判定・DB保存の条件と周期は変更しません。

検証：本体2本はMetaEditorでエラー0・警告0。隔離MT5で受信・描画・復帰・移動状態78項目と、キャッシュ検索・送信元の応答14項目が成功しました。受信ハンドラーを直接呼び、送信元のイベント引数を捕捉する検証を含みます。最初のスクリプト検証ではイベント送信が失敗したため、受信口を持つEAで再確認しました。実チャートのマウスクリックからイベント往復までの一連の操作と見た目は未確認です。記録はGit管理対象外の `output/CurrencyStrengthHistoryNavigation/` に保存しています。

## 順位履歴チャートのクリック連携（v1.37）

同一チャートに `CurrencyStrengthAllRankHistory` v1.13以降と本インジケーターを配置し、両方の計算方式（加重／均等）を揃え、「順位比較を表示」をONにします。全通貨順位履歴のサブウィンドウ内をクリックすると、位置に対応するM5時刻の長中期・中短期／全8通貨の保存順位を表示します。長中期用・中短期用のどちらの履歴窓からでも両期間を確認できます。別チャート・別端末への連携は行いません。

選択時刻には金色の縦点線を表示し、通貨順位比較と地域順位比較の見出しを「履歴」にします。通貨順位比較の下部には `yyyy/MM/dd HH:mm:ss JST`、状態欄には取得元のLIVE／TESTERを表示します。日時へマウスを重ねるとSRV時刻と集計IDを確認できます。「現在へ」で最新の集計順位へ戻り、縦線を消します。再初期化時も現在表示に戻ります。

クリック位置のチャート時刻をM5単位へ切り下げ、履歴チャートのキャッシュで完全一致する保存点だけを渡します。順位は見た目の行位置ではなく実順位を使い、同順位の並べ方も従来と共通です。欠損・未取得時は「記録なし」として順位を消し、前後の記録で埋めません。上位足チャートではそのチャートが示す時刻が基準になります。後で同じ保存点が修正された場合は、再クリックでキャッシュの変更内容を反映できます。

履歴表示中も現在の通貨強弱計算・候補判定・DB保存は継続します。スコア・売買候補・日足値幅などは現在値で、共通日時欄は「現在集計」、履歴順位パネルにも区別を表示します。現在候補から保存順位へのペア選択・AND強調は一時停止し、「現在へ」で再開します。保存順位内の通貨選択・地域選択は使用できます。

履歴選択ではDBの追加照会・保存・波動の再計算を行いません。時刻・方式・取得元・集計ID・16順位をカスタムチャートイベントで渡し、同じ内容の再受信は再描画を省きます。イベント文字列はMT5の63文字制限内に収め、形式不正・順位範囲外・異なる計算方式の受信は表示を変更せず無視します。

検証：本体2本をMetaEditorでコンパイルし、エラー0・警告0。隔離MT5で受信ハンドラーを直接呼び、形式検証、16順位、欠損、同順位、地域・通貨選択、履歴の固定、再生成、「現在へ」で更新後の現在順位へ復帰する50項目が成功しました。検証記録はGit管理対象外の `output/CurrencyStrengthHistorySelection/` に保存しています。実チャートでのマウスクリックからの一連の操作・見た目は未確認です。

## 確定H1票と順位の更新（v1.36）

各M5のH1票には、そのM5開始時点で確定しているH1足を使います。例えば17:00 SRVの集計では、16:00開始の確定H1足までの価格から短期・中期・長期のストキャスを計算します。以降は同じH1足の票を再利用します。LIVEとTESTERの計算方法は共通です。

H1票が揃うまでは、日時欄に `H1確認中 27/28` のように準備済みペア数を表示します。直前の完全な集計がある場合は、その順位と確定時刻を表示します。LIVEでは不足ペアを約2秒間隔で再確認し、全28ペアのH1票が揃ってから今回の順位・売買候補を更新し、対象M5時刻でDB保存を判定します。TESTERは既存のM5再試行を使います。

複数のMT5で同じ口座の通貨強弱を共通DBへ保存する場合は、保存担当のインジケーターを同じ版に揃えてください。同じM5時刻・口座・サーバー・計算バージョンのLIVE集計は、各端末で同じ保存先を使用します。

## 売買候補一覧の増減フィルタ（v1.35）

一覧のボタンで「増減：OFF → 長中期 → 中短期 → 両方 → OFF」の順に切り替えます。初期値は「両方」です。選択した期間の順位差が、候補の売買方向へ拡大しているものに表示を絞ります。

| モード | 増減の表示条件 |
| --- | --- |
| OFF | 増減による絞り込みなし |
| 長中期 | 長中期の増減方向が一致（中短期の増減は不問） |
| 中短期 | 中短期の増減方向が一致（長中期の増減は不問） |
| 両方（初期値） | 長中期・中短期とも候補方向に一致（AND） |

例えばBUY候補で長中期が `+2 → +4`、中短期が `+6 → +5` の場合、長中期モードでは通過し、中短期・両方モードでは除外します。単独モードでは選択していない期間の増減方向や不明状態を条件に含めません。

順位差は「決済通貨順位 − 基軸通貨順位」です。現在の候補の順位と、直前M5の順位を比較します。横ばいは直近の非ゼロの増減方向を引き継ぎます。

| 候補方向 | 選択期間の順位差の推移 | 増減条件 |
| --- | --- | --- |
| BUY | +2 → +4 | 通過 |
| BUY | +5 → +4 | 除外 |
| BUY | +2 → +4 → +4 | 上昇方向を維持して通過 |
| SELL | −2 → −4 | 通過 |
| SELL | −5 → −4 | 除外 |
| SELL | −2 → −4 → −4 | 下降方向を維持して通過 |
| 両方向 | 履歴不足・取得失敗・方向不明 | 不明として除外 |

既存の候補抽出、READY、AND、EMA200条件、NEW追跡と並び順は維持します。H1＋M1からM1への自動補完は増減フィルタ適用前の全候補で判定するため、増減で表示が0件になったことだけではM1へ切り替えません。継続3hモードとの併用時は両方の表示条件を満たす候補を表示します。継続3hの「差変化」（中短期の直近30分平均と前30分平均の比較）は変更しません。

増減フィルタの件数欄は、選択モードと、既存のAND・継続条件を通過した候補の増減通過数・対象数・不明数を表示します。両方モードではどちらかの増減方向が不明なら不明として除外します。表示件数上限は増減フィルタ適用後に使います。OFFでは増減による除外を行わず、追加の履歴検索も省きます。順位欄への増減タグや追加列は設けません。

候補の現在値は今回の集計結果を使い、DBは直前M5までの全8通貨履歴を一括取得して全候補・両期間で共用します。初回は最大30日前まで参照し、以後は末尾の履歴を更新します。正常に取得した同一M5の履歴は再利用しますが、現在候補の順位が訂正された場合は再評価します。モードを切り替えても、同じM5の取得済み履歴から選択期間だけを再評価し、選択していない期間の評価値は消去します。通常チャートでは取得失敗・直前M5不足時に60秒間隔で再試行し、テスターでは同一M5の再照会を省きます。

連続する300秒間隔の履歴だけで方向を復元し、欠損・週末などの途切れを越えて引き継ぎません。30日以内に方向を復元できない場合も不明です。履歴の取得条件は既存の全8通貨の有効な集計を使用し、LIVE優先・TESTER補完で読み取ります。DBスキーマと保存処理は変更しません。

通常チャートの選択モードは、チャートIDと集計方式ごとの専用設定へ保存します。未保存・不正な保存値では初期の「両方」を維持します。v1.34の保存済み設定がある場合は、ONを「長中期」、OFFを「OFF」として引き継ぎます。新設定が保存済みなら新設定を優先し、不正な新設定から古い設定へ戻しません。既存のEMA・AND・継続設定の保存形式は変更しません。テスターでは設定を保存・復元しません。
