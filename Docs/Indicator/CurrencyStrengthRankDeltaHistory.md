# CurrencyStrengthRankDeltaHistory

## 時間足変更時の表示残りを回収（v1.07）

時間足変更・再読み込み時に、以前の識別名のまま残った順位文字・状態欄・塗りを、初回描画前に回収します。自身のサブ画面内にあるRank Gap専用オブジェクトだけが対象です。別サブ画面の長中期・中短期表示や手描きオブジェクトは削除しません。同じサブ画面に複数のRank Gapを重ねた場合は、他の稼働中表示を保護するため、この初回清掃を行いません。

終了時の順位文字は、そのインスタンスの接頭辞でまとめて削除します。大量の文字を一つずつ照合・削除する処理を減らし、管理配列にない同じ所有名の残存文字も削除します。順位差・表示対象・通貨色・入力設定は変更しません。

## 目的と使い方

保存済みの通貨順位から、各足の「決済通貨と基軸通貨の順位差」をサブウィンドウへ折れ線で表示するインジケーターです。v1.02で各足の順位差表示に変更し、比較間隔の設定を廃止しました。ソース・ナビゲータ上の名前は `CurrencyStrengthRankDeltaHistory`、チャートの表示名は `Rank Gap` です。

MT5のナビゲータから対象通貨ペアのチャートへ追加してください。長中期と中短期を並べる場合は、表示する順位を変えて2つ追加します。M5チャートでは保存された各M5足の順位差を確認できます。

## 計算

```text
各足の順位差 = その足の決済通貨順位 − その足の基軸通貨順位
```

USDJPYの場合は、JPY順位からUSD順位を引きます。順位は小さい数字ほど強く、正の順位差は基軸通貨優位、負の順位差は決済通貨優位を表します。

| 足 | USD順位 | JPY順位 | 表示値 |
|---|---:|---:|---:|
| 10:00 | 2位 | 6位 | +4 |
| 10:05 | 1位 | 7位 | +6 |
| 10:10 | 3位 | 5位 | +2 |

この例では折れ線が **+4 → +6 → +2** とつながります。折れ線の値にはその足の順位だけを使用します。塗りの色には1本前のチャート足との比較も使用します。

順位差の値は **−7～＋7**、縦軸の表示範囲は長中期・中短期ともに **−11～＋11で固定** です。サブ画面の高さや文字に合わせて軸を自動拡張しません。折れ線の太さは2、0ラインは灰色の点線です。正は水色、負はピンク、0は灰色です。0は両通貨が同順位であることを表します。線の色は各足の順位差に応じて線分ごとに切り替え、0をまたぐ線分は途中で色を分割しません。

v1.17から、長中期・中短期ともに **＋7と−7にグレーの破線（1px）** を常時表示します。＋7は基軸通貨が1位・決済通貨が8位、−7は基軸通貨が8位・決済通貨が1位です。

v1.05では、**0ラインと折れ線の間を、直近の増減方向の色を引き継いで連続して塗ります**。線の高さ・線の色は引き続き順位差そのものを表します。

```text
前足比 = 今のチャート足の順位差 − 1本前のチャート足の順位差
```

| 前足 → 今の足 | 前足比 | その2点間の塗り |
|---|---:|---|
| +2 → +5 | +3 | 暗い青緑（上昇） |
| +5 → +2 | −3 | 暗いピンク（低下） |
| −5 → −2 | +3 | 暗い青緑（上昇） |
| −2 → −5 | −3 | 暗いピンク（低下） |
| +4 → +4 | 0 | 直前の青緑・ピンクを維持（方向不明なら灰色） |

例えば0より上でピンクの塗りなら「基軸通貨優位で、直近の変化は順位差の縮小」です。`+2 → +5 → +5 → +5 → +3 → +3` では、+5への上昇から横ばいまで青緑、+3への低下から横ばいまでピンクで塗ります。右上の前足比は、横ばいでは引き続き0を表示します。

前足から今の足までの区間を同じ色で塗り、0をまたぐ場合も増減の色を維持します。画面左端の色も、保持している履歴の古い足から直近の変化を確認するため、スクロール位置だけでは変わりません。表示期間の先頭など、直前の変化方向が分からない横ばい区間は灰色です。直前の変化が履歴の表示期間外へ出た場合も灰色へ戻ります。両端とも順位差0の区間は面積がありません。前足または今の足が欠損していればその区間を塗らず、色の引き継ぎもリセットします。欠損後は再び変化が現れるまで灰色です。

## 長中期の変化点の順位表示

**長中期の順位差が1本前のチャート足から変化した箇所**に、両通貨の順位を各通貨色で表示します。v1.18以降は塗りの上に左の通貨（基軸通貨）、下に右の通貨（決済通貨）を配置します。USDJPYでは、上がUSD、下がJPYです。

| その足の順位差 | 左の通貨順位 | 右の通貨順位 |
| --- | --- | --- |
| プラス（BUY） | 順位差線の上 | 0ラインの下 |
| マイナス（SELL） | 0ラインの上 | 順位差線の下 |
| 0（同順位） | 0ラインの上 | 0ラインの下 |

例えば `+5 → +3` は順位差がプラスなので、塗りがピンクでもBUYの配置です。順位差が0をまたぐ箇所では、文字の横幅に入る両側の塗りを避けます。

順位が上がった場合は `1↑`、下がった場合は `3↓`、変化がない場合は `3` のように表示します。矢印はそれぞれの通貨順位を直前のチャート足と比べたものです。数字が小さくなる `3位→1位` が上昇（↑）、大きくなる `1位→3位` が下降（↓）で、線の増減方向とは別です。

v1.14では、順位文字の右横へ **`差 +6（Δ+4）`** のように現在の順位差と前足からの変化量を追加します。`Δ = 現在の順位差 − 1本前のチャート足の順位差` です。例えば `+2 → +6` は `差 +6（Δ+4）`、`+6 → +2` は `差 +2（Δ-4）`、`-7 → +7` は `差 +7（Δ+14）` です。Δは±14まであり、縦軸の表示範囲には制限しません。M15では前のM15足と比較します。

v1.15では、差分ラベル全体を **Δがプラスなら買い方向の水色（Aqua）、マイナスなら売り方向のピンク（HotPink）** で表示します。例えば `差 +2（Δ-4）` はピンク、`差 -2（Δ+4）` は水色です。色は前足からの変化方向を表し、通貨順位の文字は引き続き各通貨の色を使います。Δが0の足には差分ラベルを表示しません。

両通貨の順位文字をすべて配置した後、その位置を保ったまま差分文字を追加します。線・順位文字・他の差分文字・状態欄との重なりを避け、右側へ置けない場合は左側も試します。空きがない場合は差分文字だけを省略し、順位文字のツールチップに順位差と前足比を残します。差分文字にも実測した文字の大きさと「線からの距離（目盛り）」を適用し、時間足変更・スクロール時は順位文字と一緒に更新・削除します。

入力「線からの距離（目盛り）」の初期値は **0.5** です。順位差1を1目盛りとして、文字幅の範囲で順位差線が+3なら、左通貨の文字の下端は+3.5、右通貨の文字の上端は−0.5が目安です。サブ画面を大きくすると間隔も広がり、小さくすると縮まります。

狭い画面でも文字が線へ接しないよう、最低でも文字高さの半分の余白を確保します。設定値0でもこの余白は残ります。重なり回避でさらに離れる場合があります。旧「順位文字と線の間隔（px）」は廃止し、新しい入力名に変更しています。

文字の実際の横幅にかかる0ラインと折れ線全体を確認し、上の文字はその範囲の最高位置より上、下の文字は最低位置より下へ余白を空けて配置します。縮小時に文字幅へ入る複数の折り返しも避けます。画面外へ続く線分は文字幅内の部分だけを判定し、欠損区間は接続しません。

v1.13で縦軸を自動拡張から±8固定に変更しました。

v1.16で縦軸を±10固定へ、v1.19で±11固定へ広げました。高さ140pxでは、±7から画面端までの余白が約21pxから約25.5pxになります。長中期の順位ラベルは左上の見出し、右上の状態欄、再読込ボタンの表示位置を避け、その間の空きも使います。画面中央で±7を表示できるかは、実際の文字の高さ、線からの距離、近くのラベルの位置によります。

- 順位差が `+2 → +5` に変われば、変化後の足に表示します。
- `2 / 6 → 3 / 7` のように両通貨順位が動いても、順位差が同じ `+4` なら表示しません。
- 前足が欠損している場合や、比較できる前足がない場合は表示しません。M1では同じM5枠内に重複表示しません。
- 画面内の変化点を新しい足から優先して配置し、文字が重なる場合は塗りの外側へずらします。
- 画面端や右上の状態欄などで上下に余白を確保できない場合は、その足の順位ラベルを一組で省略します。スクロール・拡大・高さ変更の際に再配置します。省略された足の両通貨順位はデータウィンドウで確認できます。
- ラベルのツールチップで通貨名・両通貨の変更前後の順位・現在の順位差・前足比・基準日時（SRV）を確認できます。

## 入力パラメータ

| 項目 | 初期値 | 選択・意味 |
|---|---|---|
| 表示する順位 | 長中期 | 長中期 / 中短期 |
| 履歴の表示日数 | 30日 | 1～366日。現在のサーバーM5時刻からさかのぼる |
| サブ画面の高さ | 140px | 0は指定なし |
| 参照する履歴 | LIVE優先／TESTER補完 | TESTER / LIVE / 実行環境に合わせる / LIVE優先／TESTER補完 |
| 参照するスコアの計算方式 | WEIGHTED | 保存側と同じ方式を選択 |
| DBファイル名 | `mstng-currency-strength.sqlite` | 年別分割時は年なしの名前 |
| 年別DBファイルを参照 | true | 既存の年別DBを参照 |
| MT5共通フォルダから読み込む | true | テスターではtrue必須 |
| 線からの距離（目盛り） | 0.5 | 0以上。順位差1＝1目盛り。長中期の順位文字に適用する上下共通の距離 |

## 時刻と欠損の扱い

- 保存履歴の単位はサーバー時刻のM5開始時刻です。M5チャートでは各M5足の順位差を表示します。
- M1では同じM5枠内の5本に同じ順位差を表示します。同じM5枠内の隣接足は前足比0でも直前の色を維持し、M5枠が変わって順位差が増減した時点で色を切り替えます。M15以上では各チャート足の開始時点の順位差を表示し、足内の順位差を平均しません。前足比も直前のチャート足との比較です。
- 対象時刻に選択期間の両通貨順位1～8がそろった場合だけ計算します。前の足が欠損していても、その足の順位差は有効です。
- 直前の別時刻の履歴で欠損を代用しません。対象時刻の履歴がなければ線を途切れさせます。ゼロは有効な値として隣接する有効値とつなぎます。
- 前後が欠損している孤立した値には線分がありません。その値はデータウィンドウ、最新足なら右上の表示でも確認できます。
- 表示期間の最古の足は、前足が表示期間外なら比較なしです。期間外の比較用データを追加取得せず、未来の時刻も参照しません。週末などチャート足自体がない区間では、直前に存在するチャート足との比較になります。
- 日時は `yyyy/mm/dd hh:mm:ss SRV`。JST変換は行いません。

DBは既存の `CurrencyStrengthRankHistory` と同じく、現在のサーバー・口座・計算方式に一致する履歴を参照します。LIVE優先／TESTER補完では同時刻のLIVEを優先し、LIVEがない時刻をTESTERで補完します。

## 表示と再読込

右上には集計期間・計算方式、順位差・前足比、基準日時・取得元を表示します。例えば `順位差 +2｜前足比 -3` です。前足と比較できない場合は `前足比 --` と表示します。両通貨順位はデータウィンドウとツールチップで確認できます。ツールチップには基準時刻・計算方法・取得状態も表示します。右上は最新のチャート足が基準で、スクロール先の足やカーソル位置には連動しません。

データウィンドウの `Rank Gap` は順位差です。`USD Rank`・`JPY Rank` など、対象通貨名を付けた項目にはそれぞれ同じ足の通貨順位を表示します。

通常チャートは新しいM5枠でDBを確認し、同じM5枠内は60秒以上経過した次の価格更新で再確認します。テスターはM5枠が変わった際に確認します。無ティック時のタイマーは表示オブジェクトの確認だけを行い、DBを取得しません。

通常更新は保存済み履歴の末尾以降を取得します。過去のTESTERデータを後から作成した場合や過去の履歴を訂正した場合は、**「再読込」**で表示期間全体を取り直してください。テスター内ではボタンを表示しません。

DB取得に失敗した場合は前回の履歴を保持し、取得状態を表示します。初回に順位データが不足している場合は空白のままです。正常に取得できた0件は、履歴なしとして反映します。

## 処理と影響範囲

DB参照、順位差の評価、パネル描画、塗りの描画、変化点の順位ラベルを別クラスに分けています。同じM5の順位差を再利用し、変更された時刻以降と新規足だけを更新します。塗りは表示中の区間だけをCanvasへ描画し、データ・画面が同じなら再描画を省略します。順位ラベルも既存バッファを使い、DB取得を増やさず可視範囲だけ配置します。パネルやラベルの文字・座標・説明は変更した項目だけ反映します。

DBの読み取り専用です。既存インジケーター、通貨順位の計算方法、エントリー条件、背景・帯、READY表示、メール通知は変更しません。

v1.06も公開済みのバッファ番号0～5を維持します。0＝従来の順位差側境界、1＝従来のゼロ側境界、2＝順位差、3＝線の色番号、4＝基軸通貨順位、5＝決済通貨順位です。0・1の値は互換性のため残し、データウィンドウには表示しません。6は内部計算用のチャート足時刻です。`iCustom`等から参照する場合は、v1.02での比較間隔入力の廃止と、v1.03でのバッファ番号変更に合わせてください。

塗りは1本前の足と今の足の2点を使い、折れ線と0の間だけを描きます。区間単位の色分けにすることで、上昇・低下が交互に出ても塗りが抜けたり、順位差が負の場合に色が逆転したりしません。欠損した足を飛ばして比較することはありません。従来の `DRAW_FILLING` 用バッファ0・1には有効値への微小オフセット `1e-8` を含めたまま保持しますが、Canvasの描画・順位差・通貨順位の計算には使用しません。
