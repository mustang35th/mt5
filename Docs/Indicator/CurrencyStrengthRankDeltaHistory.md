# CurrencyStrengthRankDeltaHistory

## 目的と使い方

保存済みの通貨順位から、各足の「決済通貨と基軸通貨の順位差」をサブウィンドウへ折れ線で表示するインジケーターです。v1.02で各足の順位差表示に変更し、比較間隔の設定を廃止しました。ソース・ナビゲータ上の名前は `CurrencyStrengthRankDeltaHistory`、チャートの表示名は `Rank Gap` です。

MT5のナビゲータから対象通貨ペアのチャートへ追加してください。長中期と中短期を並べる場合は、表示する順位を変えて2つ追加します。M5チャートでは保存された各M5足の順位差を確認できます。

## 計算

```text
各足の順位差 = その足の決済通貨順位 − その足の基軸通貨順位
```

USDJPYの場合は、JPY順位からUSD順位を引きます。順位は小さい数字ほど強く、正の順位差は基軸通貨優位、負の順位差は決済通貨優位を表します。

| 足 | USD順位 | JPY順位 | 表示値 |
|---|---:|---:|---:|
| 10:00 | 2位 | 6位 | +4 |
| 10:05 | 1位 | 7位 | +6 |
| 10:10 | 3位 | 5位 | +2 |

この例では折れ線が **+4 → +6 → +2** とつながります。その足の順位だけを使用し、前の足のデータは必要としません。

縦軸は **−7～＋7で固定**、折れ線の太さは2、0ラインは灰色の点線です。正は水色、負はピンク、0は灰色です。0は両通貨が同順位であることを表します。線の色は各足の順位差に応じて線分ごとに切り替え、0をまたぐ線分は途中で色を分割しません。

v1.03では、**0ラインと折れ線の間を塗りつぶします**。正の領域は暗めの水色、負の領域は暗めのピンクです。明るい折れ線を塗りの上に描き、方向と順位差の大きさを見やすくします。0では面積がなく、欠損区間は線・塗りとも途切れます。

## 入力パラメータ

| 項目 | 初期値 | 選択・意味 |
|---|---|---|
| 表示する順位 | 長中期 | 長中期 / 中短期 |
| 履歴の表示日数 | 30日 | 1～366日。現在のサーバーM5時刻からさかのぼる |
| サブ画面の高さ | 140px | 0は指定なし |
| 参照する履歴 | LIVE優先／TESTER補完 | TESTER / LIVE / 実行環境に合わせる / LIVE優先／TESTER補完 |
| 参照するスコアの計算方式 | WEIGHTED | 保存側と同じ方式を選択 |
| DBファイル名 | `mstng-currency-strength.sqlite` | 年別分割時は年なしの名前 |
| 年別DBファイルを参照 | true | 既存の年別DBを参照 |
| MT5共通フォルダから読み込む | true | テスターではtrue必須 |

## 時刻と欠損の扱い

- 保存履歴の単位はサーバー時刻のM5開始時刻です。M5チャートでは各M5足の順位差を表示します。
- M1では同じM5枠内の5本に同じ順位差を表示します。M15以上では各チャート足の開始時点の順位差を表示し、足内の順位差を平均しません。
- 対象時刻に選択期間の両通貨順位1～8がそろった場合だけ計算します。前の足が欠損していても、その足の順位差は有効です。
- 直前の別時刻の履歴で欠損を代用しません。対象時刻の履歴がなければ線を途切れさせます。ゼロは有効な値として隣接する有効値とつなぎます。
- 前後が欠損している孤立した値には線分がありません。その値はデータウィンドウ、最新足なら右上の表示でも確認できます。
- 表示範囲より前の比較用データを取得する必要はありません。未来の時刻は参照しません。
- 日時は `yyyy/mm/dd hh:mm:ss SRV`。JST変換は行いません。

DBは既存の `CurrencyStrengthRankHistory` と同じく、現在のサーバー・口座・計算方式に一致する履歴を参照します。LIVE優先／TESTER補完では同時刻のLIVEを優先し、LIVEがない時刻をTESTERで補完します。

## 表示と再読込

右上には集計期間・計算方式、順位差・両通貨順位、基準日時・取得元を表示します。例えば `順位差 +4｜USD 2位 / JPY 6位` です。ツールチップでは基準時刻・計算方法・取得状態を確認できます。右上は最新のチャート足が基準で、スクロール先の足やカーソル位置には連動しません。

データウィンドウの `Rank Gap` は順位差です。`USD Rank`・`JPY Rank` など、対象通貨名を付けた項目にはそれぞれ同じ足の通貨順位を表示します。

通常チャートは新しいM5枠でDBを確認し、同じM5枠内は60秒以上経過した次の価格更新で再確認します。テスターはM5枠が変わった際に確認します。無ティック時のタイマーは表示オブジェクトの確認だけを行い、DBを取得しません。

通常更新は保存済み履歴の末尾以降を取得します。過去のTESTERデータを後から作成した場合や過去の履歴を訂正した場合は、**「再読込」**で表示期間全体を取り直してください。テスター内ではボタンを表示しません。

DB取得に失敗した場合は前回の履歴を保持し、取得状態を表示します。初回に順位データが不足している場合は空白のままです。正常に取得できた0件は、履歴なしとして反映します。

## 処理と影響範囲

DB参照、順位差の評価、パネル描画を別クラスに分けています。同じM5の計算結果を再利用し、変更された時刻以降と新規足だけを更新します。パネルの文字・色・説明も変更した項目だけ反映します。

DBの読み取り専用です。既存インジケーター、通貨順位の計算方法、エントリー条件、背景・帯、READY表示、メール通知は変更しません。

v1.03のバッファは、0＝塗りの順位差側、1＝塗りのゼロ側、2＝順位差、3＝色番号、4＝基軸通貨順位、5＝決済通貨順位です。塗りの2バッファは描画専用でデータウィンドウへ表示しません。`iCustom`等から参照する場合は、v1.02での比較間隔入力の廃止と、v1.03でのバッファ番号変更に合わせてください。

塗りにはMQL5の `DRAW_FILLING` を使用します。この方式は `EMPTY_VALUE` の区間をつなぐため、欠損には両境界0を設定します。有効な順位差0を欠損と区別するため、描画専用の2境界には同じ微小値 `1e-8` を加えます。順位差・通貨順位の計算値は変更しません。[MQL5公式仕様](https://www.mql5.com/ja/docs/customind/indicators_examples/draw_filling)
